Roofing contractors who are getting leads from a few different places, like website forms, referrals, and inquiries, but don't have a consistent system to follow up with all of them.

n8n · Leads Automation

Booked-Call Reminder & Follow-Up

Triggered off a Google Calendar booking, this workflow sends a confirmation email, then automatic reminders at 24hrs and 1hr before the call, no lead falls through the cracks between booking and showing up.

n8n · AI Assistant

AI Chat Agent That Books Calls

A Gemini-powered agent that answers client questions from a knowledge base, checks real availability on the calendar, books the call, and logs the full conversation to the CRM and a Sheets log automatically.

n8n · Questionnaire Generator

AI-Generated Client Questionnaires

Called directly by the CRM, this workflow checks an API key, builds a prompt, and has Gemini generate a tailored set of qualifying questions, validating the output before it ever reaches the client.
